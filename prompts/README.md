# Prompts

Add the rendered adversary-knowledge prompts here before uploading:

  K0.txt   Blind: published artifacts and the task, nothing about a flaw
  K1.txt   Disclosure-aware: the flaw exists, plus its CVE identifier
  K2.txt   Specification-aware: the full mechanism, no procedure

Each file is the system prompt, the knowledge block, and the task template, with
the voter name replaced by a placeholder such as <VOTER NAME>.

The K3 (procedure-equipped) prompt is withheld, as the paper's Open Science
section states; it is available to researchers and election officials on request.
